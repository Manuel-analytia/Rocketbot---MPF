3. REGLAS APRENDIDAS DE ROCKETBOT
===============================================================================

REGLA 1: setVar con GetVar() NO funciona
    [setVar] v_x = GetVar("a") + "\\" + GetVar("b")   -> FALLA, deja v_x='ERROR_NOT_VAR'
    Usar siempre execScriptPython: SetVar('v_x', os.path.join(GetVar('a'), GetVar('b')))

REGLA 2: Variables entre bots hijos NO se heredan
    execRocketBotDB crea un scope donde GetVar("v_x") devuelve 'ERROR_NOT_VAR'
    para cualquier variable no declarada en el MODULO del bot hijo.

REGLA 3: Variables no-modulo se pierden entre comandos
    Dentro de un mismo bot, si haces SetVar('v_x', 'algo') en un execScriptPython
    y v_x no esta en el modulo del bot, el SIGUIENTE comando ve 'ERROR_NOT_VAR'.
    Las variables del modulo persisten; las no-modulo se reinician.

REGLA 4: GetVar para undefined retorna 'ERROR_NOT_VAR' (no '' ni None)
    Validar siempre: if valor and valor != 'ERROR_NOT_VAR':

REGLA 5: execRocketBotDB busca bots por NOMBRE
    Hay multiples bots con el mismo nombre (1_Crear_Carpetas: IDs 7,11,14,15,19,22,26)
    Rocketbot resuelve por nombre. Bot 26 es el SAN ISIDRO confirmado.
