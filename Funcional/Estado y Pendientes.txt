4. FLUJO DE DESPLIEGUE (repo -> OneDrive -> Servidor)
===============================================================================

LOCAL (maquina de dev):
    1. Aplicar patch:  python .audit/patch_*.py
    2. Validar:        ast.parse + smoke tests
    3. Commit + push al repo Git

DISTRIBUCION:
    Copiar robot.db local a OneDrive del cliente:
       {ROOT_ONEDRIVE}\SAN ISIDRO - PROGRAMACION SEMANAL DE EMBARQUES\
                       0. Bot\robot.db
    OneDrive sincroniza automaticamente al servidor MPFBOOT01.

SERVIDOR (MPFBOOT01, Task Scheduler):
    Funcional/bot_comex_from_repo.bat:
       1. Lanza OneDrive si no esta corriendo
       2. Espera SYNC_WAIT_SEC (120s en server)
       3. copy /Y {OneDrive}\...\0. Bot\robot.db -> {ROCKETBOT_DIR}\robot.db
       4. Ejecuta rocketbot.exe -start=0_Flujo_Regular
